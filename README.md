# phone-buying-guide

OpenSquilla Skill：提问式手机选购顾问（v1）

像懂行的朋友一样帮你选手机：先访谈明确"人和钱"，再联网核实参数与多渠道比价，最后给出能直接下单的建议，或面向大众的选购内容。方法论由 AI 掌握，用户不需要懂参数。

## 特性

- **提问式访谈**：两轮收敛（性别/年龄段侧重追问、参数熟悉度自适应问法），一轮 4-5 问，拒绝问卷轰炸
- **动态一票否决**：避坑规则按本次访谈现场生成，不写死（预算 vs 需求、战 N 年的性能冗余、轻薄 vs 配置……）
- **旧机价值拆解**：残值不等式 = 二手残值 vs 旧机仍可用能力的替代成本，结论只有三种——淘汰 / 改役留用 / 以旧换新，各带账本
- **倒退检查**：新机相对旧机逐维度"持平或更强"，隐性回退（换大电池但充电更慢、砍耳机孔、变重）强制摆上台面
- **信息源地图**：参数（中关村在线 → 官网规格页）、实测表现（评测数据库）、价格（京东/拼多多多渠道 + 国补到手价）、历史价（识别假促销）
- **搜索故障降级 SOP**：多引擎直连脚本 → 直抓搜索页快照，含实测坑位与快照采信规则
- **零机型数据架构**：SKILL.md 只沉淀方法论，所有机型/价格事实现场联网采集，行情快照外部化——新手机发布零维护

## 安装

将本仓库放入 OpenSquilla 工作区的 `skills/phone-buying-guide/` 目录（即 `SKILL.md` 位于该目录下），之后对助手说：

> 帮我选手机 / 换机 / 手机推荐

即可触发访谈流程。

## 输出结构

3 秒结论 → 需求画像 → 候选对比表 → 升级 vs 倒退一页账 → 最终建议 → 避坑提醒 → 渠道与时机 → 旧机处置账本 → 数据置信声明

## 适用范围

数码选购系列第一块拼图（v1 = 手机），方法论骨架可复用于耳机/平板/笔记本等品类。
